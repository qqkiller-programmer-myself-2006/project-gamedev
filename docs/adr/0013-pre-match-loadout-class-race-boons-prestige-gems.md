# เลือกอาชีพ เผ่าพันธุ์ และพร ก่อนเริ่มแมตช์ตาม AAC พร้อมผังทักษะ เกียรติยศ และอัญมณีที่เก็บบนเซิร์ฟเวอร์ (แทนการเริ่มแบบไร้อาชีพ)

เจ้าของงานตัดสิน (2026-09-29) ให้หน้าก่อนเริ่มแมตช์เหมือนภาพ `docs/references/aac_rogue/01–03`: เลือกอาชีพก่อนเริ่มแบบ AAC, อ่อนแรงเป็นพรตามภาพ, เผ่า "Robloxian" เปลี่ยนชื่อเป็น **มนุษย์** และอัญมณีเก็บข้ามเกมบนเซิร์ฟเวอร์ (Cloudflare D1)

## 1. หน้าจัดตัวละคร (ในห้องก่อนเจ้าของห้องกดเริ่ม)

- แถบไอคอนกลม 5 อันด้านบน: `Profile`, `Races`, `Class`, `Boons`, `Records`; ปุ่ม `Finish` ด้านล่างกลับไปหน้าห้อง
- ทุกการเลือกส่งคำสั่งไปที่เซิร์ฟเวอร์ระหว่างอยู่ในห้องเท่านั้น (`set_loadout`, `buy_race`, `tree_upgrade`, `buy_prestige`, `reset_tree`) เซิร์ฟเวอร์ตัดสินและหักอัญมณี (ADR-0001)
- มุมซ้ายล่างแสดงอัญมณี (ไอคอนเพชรสีเขียว)

## 2. อาชีพก่อนเริ่ม (แทนการเริ่มแบบไร้อาชีพ)

- ผู้เล่นจริงเลือกอาชีพระดับ 1 (นักดาบ, นักธนู, นักเวท, ผู้พิทักษ์, นักฆ่า) ในหน้าอาชีพแบบภาพเลื่อน `< >` พร้อมคำอธิบายและข้อความ "Recommended Stats" (เปลี่ยนชื่อจาก Rogue ตาม #74)
- ช่องของ AI ได้อาชีพที่ยังไม่มีในกลุ่มตามลำดับใน `party.ai_class_order` (ถ้าผู้เล่นไม่ได้ส่งชุดตัวละครเลย ตัวละครเริ่มไร้อาชีพแบบเดิม — ใช้โดยการทดสอบเดิมและไคลเอนต์เก่า)
- **เหตุการณ์อาชีพ** ยังอยู่: ชนะการประลองได้ EXP + อัญมณีแทนการรับอาชีพ; ตัวละครที่ยังไร้อาชีพ (กรณีไม่มีชุดตัวละคร) ยังรับอาชีพได้เหมือนเดิม
- **ผังทักษะต่ออาชีพ**: 7 จุด (ผัง 3–3–1 ตามภาพ) แต่ละจุดสูงสุด 5/5, ราคา `10 × level ถัดไป` อัญมณี, ข้อมูลอยู่ใน `meta.class_tree` ของข้อมูลเกม
  - แต้มคุณลักษณะ: +1 แต้มคุณลักษณะที่ลงได้ตอนเริ่มแมตช์ต่อระดับ
  - พลังชีวิต +2% ของพลังชีวิตสูงสุด, พลังโจมตี +2% ของความเสียหายโดยตรง, ความแม่นยำ +1% โอกาสคริติคอล, ความว่องไว +1 ชิงจังหวะต่อ 2 ระดับ, พลังสำรอง +1 พลังงานตอนเริ่มการต่อสู้ที่ระดับ 5, ความเชี่ยวชาญ (จุดล่าง) ลดคูลดาวน์ของทักษะอาชีพ 1 ที่ระดับ 5
- **เกียรติยศ**: เมื่อทุกจุด 5/5 กด **Buy Prestige** (100 อัญมณี) → เกียรติยศ +1 (สูงสุด 25 = MAX) และรีเซ็ตจุด; เกียรติยศแต่ละระดับให้พลังชีวิตสูงสุดและความเสียหายของอาชีพนั้น +1%
- `Reset Skills` (50 อัญมณี): คืนอัญมณีที่ใช้ในผังทักษะของอาชีพนั้นทั้งหมด

## 3. เผ่าพันธุ์

| เผ่าพันธุ์ | ราคา | ความสามารถติดตัว 1 | ความสามารถติดตัว 2 |
| --- | --- | --- | --- |
| มนุษย์ | ฟรี | ปรับตัว: +1 แต้มคุณลักษณะทุกระดับคู่ | รอบด้าน: คุณลักษณะทุกอย่าง +1 |
| เอลฟ์ | ฟรี | สายตาเฉียบคม: โอกาสคริติคอล +5% | สง่างาม: DEX +2 |
| โคโบลด์ | ฟรี | เอาตัวรอดเก่ง: ทองจากรางวัล +10% | เป้าหมายขนาดเล็ก: หลบหลีก +5% |
| ผู้เหี่ยวเฉา | ฟรี | ไม่ตาย: ดูดพลังชีวิต 5% | เปราะบาง: พลังชีวิตสูงสุด −10% |
| คนแคระ | 50 อัญมณี | ความทรหดของคนแคระ: พลังชีวิตสูงสุด +10%, ต้านทานสถานะ +10% | งานฝีมือชั้นเยี่ยม: ค่าสถานะของอุปกรณ์ที่คราฟต์ได้ +0.75% ต่อระดับปัจจุบัน |
| ลูนาเอีย | 100 อัญมณี | แสงจันทร์: ความเสียหายเวท +10% | กระแสน้ำ: พลังงานตอนเริ่มการต่อสู้ +1 |

- **ต้านทานสถานะ** (ค่าสถานะที่คำนวณใหม่): โอกาสไม่ติดสถานะที่ศัตรูใส่

## 4. พร

- ความจุ 5 ช่อง; รายการแบ่งกลุ่มตามจำนวนช่องที่ใช้ มีช่องค้นหา; ฝั่งขวาแสดงพรที่ใส่และ `Slots: x/5`
- **อ่อนแรงย้ายจากความสามารถติดตัวของนักฆ่า (เดิม Rogue) มาเป็นพร** (ผลเหมือน ADR-0010 เดิม) — นักฆ่าไม่มีความสามารถติดตัวนี้แล้ว

| พร | ช่อง | ผล |
| --- | --- | --- |
| ศักยภาพ: กระต่าย | 5 | ชิงจังหวะ +3, หลบหลีก +15% |
| ผู้ถูกเลือก | 4 | คุณลักษณะทุกอย่าง +2 (ปลดล็อกเมื่อมีเกียรติยศรวม ≥ 5) |
| แรงกระตุ้นบ้าระห่ำ | 3 | ความเสียหาย +25% เมื่อพลังชีวิต ≤ 30% |
| เยียวยาคริติคอล | 3 | เมื่อคริติคอล รักษาตัวเอง 20% ของความเสียหาย |
| ผู้ประหยัดพลังงาน | 2 | โอกาส 15% ได้พลังงาน +1 เพิ่มตอนเริ่มเทิร์น |
| อ่อนแรง | 2 | ตาม ADR-0010 |
| ตื่นตัว | 1 | ชิงจังหวะ +3; 2 เทิร์นแรกของการต่อสู้ ปัดป้องและหลบหลีก +5% |
| เจตจำนงแห่งธีแอกเดโม | 1 | ครั้งแรกต่อการต่อสู้ที่โดนความเสียหายจนล้ม เหลือพลังชีวิต 1 แทน |

## 5. อัญมณีและการเก็บข้อมูล

- ได้อัญมณีตอนจบแมตช์: +10 ต่อชั้นที่ผ่าน, +50 เมื่อชนะบอสผู้พิทักษ์, +5 ต่อเบาะแสเรื่องราว, +อัญมณีจากเหตุการณ์อาชีพ
- **ตัวตนผู้เล่น**: ไคลเอนต์สร้างโทเคนสุ่ม 128 บิตครั้งแรกแล้วเก็บใน `user://` ส่งมาตอนเข้าห้อง; โปรไฟล์ผูกกับโทเคนนี้ (ไม่มีรหัสผ่าน)
- **ProfileStore** เป็นจุดเชื่อมที่ MatchServer รับจากภายนอก (เหมือน clock/rng): `MemoryProfileStore` สำหรับการทดสอบ, `FileProfileStore` (ค่าเริ่มต้นของเซิร์ฟเวอร์ในเครื่อง) และ `D1ProfileStore` เรียก Cloudflare Worker (`deploy/profile-worker/`) ที่ผูก D1 ผ่าน HTTPS พร้อมรหัสลับของเซิร์ฟเวอร์
- การบันทึกเป็นแบบไม่รอผล: แมตช์ไม่รอเครือข่าย; ถ้าบันทึกไม่สำเร็จเซิร์ฟเวอร์บันทึกเหตุการณ์และลองใหม่

## ตัวเลือกที่พิจารณา

- **เก็บอัญมณีในไฟล์ของไคลเอนต์**: ง่ายที่สุด แต่โกงได้และไม่ตามข้ามเครื่อง — เจ้าของงานมี Cloudflare D1/R2 ระดับใช้งานฟรีจึงเลือกเซิร์ฟเวอร์
- **คงการเริ่มแบบไร้อาชีพ**: รักษาเรื่องราวเดิม แต่ไม่ตรงภาพที่เจ้าของงานต้องการ
