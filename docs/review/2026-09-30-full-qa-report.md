## 2. บั๊กระบบเกม (Game logic)

| รหัส | ระดับ | ปัญหา | วิธีเกิด → ผลที่ผิด | แนวทางแก้ |
|---|---|---|---|---|
| **B1** | P1 | Skill tree "Stat Points" ให้แต้มซ้ำทุกเลเวล | `match_run.gd:317` บวก `_tree_level("stat_points")` ทุกครั้งที่เลเวลอัป ทั้งที่กติกา (ADR-0013) คือ "แต้มเริ่มต้น +1 ต่อระดับ" → โหนด 5/5 ได้ 7 แต้มต่อเลเวลแทน 2 (เกินราว 30 แต้มต่อแมตช์) เฉพาะ Multiplayer | ลบบรรทัด 317 (ตอนเริ่มแมตช์ให้ถูกอยู่แล้วที่ :406) |
| **B2** | P1 | Shield Wall ยังทำงานหลัง Guardian ตาย | โล่ถูกล้างเฉพาะตอนเริ่มเทิร์นของผู้ร่าย แต่คนตายไม่ได้เทิร์น → ทั้งปาร์ตี้รับดาเมจแค่ 60% ไปจนจบไฟต์ | ตอน HP ถึง 0 ให้ล้าง shields/Protect/defending/focusing ของยูนิตนั้น (helper เดียว เรียกจาก `_hit` และ DoT) |
| **B3** | P2 | สถานะติดตัวข้ามความตาย | ตายจากการโจมตีตรงไม่ล้างสถานะ (ตายจาก DoT ล้าง) → ชุบด้วย Spirit Bloom แล้ว Bleed เดิมยังติ๊กต่อ; ศัตรูที่ตายแล้วยังโชว์ badge | ใช้ helper เดียวกับ B2 เรียก `status_book.clear_unit` |
| **B4** | P2 | Boss ถูกนับเป็น Layer เพิ่มตอนคิด Gems | ชนะได้ 110 Gems แทน 100 (6x10+50) | นับ `layers_passed` เฉพาะตอนไม่ใช่ boss |
| **B5** | P2 | AI ใช้ยาจริงใน Class trial (ที่ไม่มีใครตาย) | trial จบแล้ว HP ถูกคืนเท่าเดิม ยาหายฟรี | ข้าม `_healing_item` ตอนเป็น trial |
| **B6** | P2 | AI ไม่ใช้ช่อง Consumable ของตัวเอง | ผู้เล่นหลุด → AI คุมแทน ช่อง Consumable มี Herb แต่คลังว่าง → ไม่ฮีลเลยแม้ HP วิกฤต | ให้ AI ดู `me["consumable"]` ด้วย |
| **B7** | P2 | `skeleton.resistances` ไม่มีผล | คำอธิบายว่ากระดูกลดดาเมจกายภาพ แต่โค้ดไม่อ่านคีย์นี้ | ใช้ใน `_hit` ข้างๆ weakness หรือแก้คำอธิบาย |
| **B8** | P2 | `craft` รับ id ที่มีจุด → ได้ไอเท็มขยะฟรี | ส่ง `pelt_boots.materials` → ไม่ต้องใช้วัตถุดิบ ได้ไอเท็มแปลกในคลัง (ออฟไลน์ทำให้ save Story ใช้ไม่ได้) | เช็ค key ตรงตัวใน `crafting.recipes` |
| **B9** | P2 | ค่าตัวเลขผิดรูปแบบจาก client ทำให้ไม่มีคำตอบกลับ | `{"type":"vote","option":[1]}` → script error, client ไม่ได้ `result` (state ไม่เสีย) | ตรวจชนิดใน `MatchServer.command` แล้วตอบ `invalid_command` |

สิ่งที่ตรวจแล้ว **แข็งแรงดี**: สิทธิ์สั่งเฉพาะช่องตัวเอง, flag dev/story ใช้จากออนไลน์ไม่ได้, การโอนของ/ทองไม่สร้างหรือทำหายของ,
ศัตรู/บอสเลือกเป้าเฉพาะคนที่ยังมีชีวิต, Story ไม่มี timer ฝั่งเซิร์ฟเวอร์, Gems บันทึกครั้งเดียวต่อแมตช์

## 5. ความสมูทของการแสดงผล (Smoothness)

5 อย่างที่จะทำให้เกมรู้สึก "ลื่น" ขึ้นมากที่สุด เรียงตามผลที่ได้:

| รหัส | ปัญหา | แนวทาง |

| **S2** | ลำดับเหตุการณ์ผิด: HP ลดก่อนท่าโจมตีเล่น | คิวต่อ action: ท่าโจมตี (~0.3 วิ) → โดน + flash + เลขดาเมจ → แถบ HP ลด; แบนเนอร์สั้นและไม่บล็อก (ผูกกับ U2) |

## 6. จังหวะเกม (Pacing) — ข้อสังเกตให้ตัดสินใจ
