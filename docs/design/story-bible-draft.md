# Story bible — ร่างที่ 3 (Story mode offline)

สถานะ: **ร่างเพื่อรอเจ้าของงานรีวิว** ยังไม่แตะ `content/story_mode.json` หรือ `content/forest.json`
เขียนใหม่ทั้งหมดแทนสตอรี่เดิม (Arin/Bram/Cora/Dain/Wren, ตามหาพ่อ) การตัดสินใจเชิงระบบอยู่ใน [ADR-0016](../adr/0016-story-reboot-new-classes-auto-battle.md)

หัวข้อ "ที่เจ้าของงานกำหนดแล้ว" มาจากเจ้าของงานโดยตรง ส่วน "ข้อเสนอ" ผู้ร่างเติมให้และรอยืนยัน

## ที่เจ้าของงานกำหนดแล้ว

### โลกและเรื่อง
- ทีมนักผจญภัยเดิมมี **6 คน เป็น 3 คู่ ชาย–หญิง**: ไอคิว+แนนนี่, ฟีฟ่า+เค้ก, ตาต้า+เมย์ แต่ละคู่เป็น **เพื่อนสนิทที่แอบคิดเกินเพื่อน และไม่เคยพูดออกมา**
- **แนนนี่คือคนที่ 6 ที่หายไป** เพื่อนวัยเด็กและรักแรกของไอคิว อดีตเป็นฮีลเลอร์ ถูก **ฝ่ายอสูรเก็บไปเลี้ยงและล้างสมองให้รับใช้ฝ่ายอสูร** จึงจำไอคิวไม่ได้
- ทีม 5 คนปัจจุบันรับภารกิจจาก **เมืองหลวง** ระหว่างทางไอคิวเดินสวนกับแนนนี่
- **ความจริงของโลก:** ฝ่ายอสูรไม่ได้เป็นภัยต่อมนุษย์โดยธรรมชาติ ทั้งอสูรและมนุษย์มีดีและไม่ดี ความขัดแย้งเกิดจาก **เมืองหลวงและศาสนจักรปลูกฝังเด็กทุกคนให้เกลียดอสูร**
- เพลงเปิดมีแก่นว่า **"ไม่ได้ลืม แค่ไม่ได้เจอ"** มีเพลงตอนจบ (เจ้าของงานเตรียมเอง)
- ภาษา: บทพูดและข้อความเรื่องเป็น **ภาษาไทย** ไทยเป็นค่าเริ่มต้นของทั้งเกม รองรับไทยอย่างเดียวก่อน
- ฉากเกมแพ้แยกตามความคืบหน้า (ตาม Layer)
- **Support = บัฟ/ดีบัฟและเพิ่ม Energy ให้เพื่อน, Healer = ฟื้น HP และล้าง Status effect**
- **ปุ่ม Auto มีในทุกการต่อสู้** ของ Story mode แต่ **Auto ไม่ข้าม/ไม่เล่น cutscene แทนผู้เล่น**
- ในรูท 2 เพื่อน 4 คนที่เป็นศัตรู **ใช้อาชีพที่ผู้เล่นเลือกไว้** (ไม่ตายตัว)

### ตัวละครและอาชีพ
ชื่อ เพศ และหน้าตาล็อกตายตัว ผู้เล่นเปลี่ยนอาชีพได้เฉพาะภายในกลุ่มเพศเดียวกัน เพื่อจำกัดจำนวน cutscene

| ตัวละคร | เพศ | อาชีพเริ่มต้น |
| --- | --- | --- |
| ไอคิว | ชาย | Assassin |
| ฟีฟ่า | ชาย | Archer |
| ตาต้า | ชาย | Guardian (แทงค์) |
| เค้ก | หญิง | Support |
| เมย์ | หญิง | Mage |
| แนนนี่ | หญิง | Healer (อดีต ไม่อยู่ในปาร์ตี้ผู้เล่น) |

- **กลุ่มชาย** (ไอคิว, ฟีฟ่า, ตาต้า) เลือกได้: Assassin / Archer / Guardian
- **กลุ่มหญิง** (เค้ก, เมย์) เลือกได้: Mage / Support / Healer
- **เพิ่มอาชีพใหม่ Support และ Healer** ให้เข้ากับเรื่อง
- Swordsman ยังอยู่ในเกม (Multiplayer) แต่ไม่อยู่ในกลุ่มของ Story mode

### ลักษณะภายนอก (เจ้าของงานกำหนด สำหรับ character sheet และ prompt ภาพ)
- ตัวละครหญิงทุกคน (แนนนี่, เค้ก, เมย์) **สวมแว่นตา** เป็นลายเซ็นของกลุ่ม
- สัดส่วนรูปร่างของตัวละครหญิง: **แนนนี่ G cup, เมย์ E cup, เค้ก D cup** ใช้เป็นข้อมูลอ้างอิงเพื่อให้ภาพทุกชิ้น (portrait, โมเดล 3D, วิดีโอ) สม่ำเสมอ ไม่ใช่เนื้อหาที่จะนำเสนอในเชิงเรื่องเพศ
- ตัวละครทุกตัวเป็น **ผู้ใหญ่** (ผู้ร่างถือเป็นข้อกำหนดการออกแบบ ต้องระบุอายุจริงของแต่ละคนใน character sheet)
- ยังไม่กำหนด: ลักษณะของตัวละครชาย, สีผม/ดวงตา/ชุดเรื่องของทุกคน, อายุ
- ข้อสังเกตทางเรื่อง (เสนอ): แว่นของแนนนี่เป็นสิ่งที่ยังอยู่หลังถูกล้างสมอง เป็นร่องรอยเดียวของตัวตนเดิม ใช้ในฉาก Layer 3 และรูท 1 ได้

### 3 รูทจบ
1. **ทุกคู่ได้คู่กันและจบสวย** แนนนี่ได้ความทรงจำคืน
2. **ไอคิวสังหารเพื่อนทั้ง 4 เพื่อไปอยู่ฝ่ายเดียวกับแนนนี่** ฉากนี้เป็นการต่อสู้จริงที่ไม่มีใครชนะไอคิวได้ ผู้เล่นควบคุมได้เอง และมี **ปุ่ม Auto** เมื่อเพื่อนทั้ง 4 ตาย ตัดเข้า cutscene
3. **ทุกคนรอดทั้งหมด แต่ถูกเมืองหลวงหักหลัง**

## ข้อเสนอ

### ชื่อ (ร่าง รอยืนยัน)
| สิ่งที่ตั้งชื่อ | ชื่อที่เสนอ | หมายเหตุ |
| --- | --- | --- |
| เมืองหลวง | **เวียงอรุณ** | เมืองแห่งแสง ดูอบอุ่นจากข้างนอก |
| ศาสนจักร | **จักรแห่งอรุณ** | ผู้ปลูกฝังให้เกลียดอสูร |
| ฝ่ายอสูร / ดินแดนอสูร | **แดนราตรี** | ไม่ใช่นรก เป็นอีกโลกหนึ่ง |
| ถ้ำ Layer 5 | **ถ้ำเสียงก้อง** | โยงกับเพลงเปิด (เสียงที่ยังไม่ถึงกัน) |
| Guardian Boss | **เซลเลน ผู้เฝ้าประตูราตรี** | อสูรผู้ดี เฝ้าประตูระหว่างสองโลก ที่ช่วยปกป้องแนนนี่ ผู้เล่นสู้เพราะถูกปลูกฝัง |
| ผู้ล้างสมองแนนนี่ | **ลอร์ดวาเลน** | อสูรฝ่ายแข็งกร้าว ตัวร้ายฝั่งอสูร |
| ผู้นำศาสนจักร | **พระมหาเถระอัครเสน** | ตัวร้ายฝั่งมนุษย์ ผู้สั่งภารกิจ |

### กลไกเลือกรูท
ที่ประตูถ้ำ (Layer 5) มีฉากตัดสินใจ (decision point ของระบบ cutscene):

| ตัวเลือก | ความหมาย | รูท |
| --- | --- | --- |
| อยู่กับเพื่อนในทีม | ไอคิวเลือกปกป้องทุกคน | 1 |
| เลือกแนนนี่ | ไอคิวเลือกเธอเหนือทุกคน | 2 |
| ทำตามคำสั่งเมืองหลวง | ทำภารกิจจนจบตามที่ได้รับ | 3 |

เรื่องใน Layer 1–4 วางเงื่อนงำให้ทั้งสามทางสมเหตุสมผล: ความรู้สึกที่ไม่พูดของสามคู่, เบาะแสว่าอสูรไม่ใช่ศัตรู, หลักฐานว่าเมืองหลวงปิดบังเรื่องแนนนี่

### โครงเรื่อง 5 Layer + บอส
1. **ออกจากเวียงอรุณ:** เพลงเปิด ทีม 5 คนรับภารกิจจากพระมหาเถระ เผยว่าทีมเคยเสียแนนนี่ไป
2. **ร่องรอยเก่า:** ของของทีมเดิม ความรู้สึกที่ไม่พูดของแต่ละคู่
3. **เดินสวนกัน:** ไอคิวเจอแนนนี่ในบทบาทผู้รับใช้ฝ่ายอสูร เธอจำไม่ได้
4. **ความจริงเริ่มเผย:** พบอสูรที่ดี เบาะแสการปลูกฝังของจักรแห่งอรุณ เมืองหลวงรู้เรื่องแนนนี่
5. **ถ้ำเสียงก้อง:** ฉากตัดสินใจ แล้วสู้เซลเลน (หรือสู้เพื่อน ในรูท 2) และฉากจบตามรูท
ฉากเกมแพ้มีแยกต่อ Layer

### Cutscene กับอาชีพที่เปลี่ยนได้
วิดีโอ cutscene ใช้ **ชุดเรื่องตายตัวต่อตัวละคร ไม่ผูกกับอาชีพ** อาชีพโชว์เฉพาะฉาก 3D และ portrait ในเกม ทำให้จำนวนวิดีโอไม่เพิ่มตามการเลือกอาชีพ บทพูดที่อ้างอาชีพให้หลีกเลี่ยงหรือใช้ตัวแปรข้อความ

## ผลกระทบต่อระบบ (สรุป รายละเอียดใน ADR-0016)
- เพิ่ม Class **Support** และ **Healer** (server, content, skill, AI preset, balance, icon, sprite, test)
- เพิ่ม encounter พิเศษรูท 2 พร้อมกติกา "ไอคิวตายไม่ได้" และปุ่ม **Auto** ทำงานต่อ slot
- เปลี่ยน `party.members` และเนื้อหา Story ทั้งหมดเป็นชุดใหม่ ภาษาไทย
- ปรับ ADR-0007 (ข้อความเกม) และ `CONTEXT.md` (ศัพท์ Class, ตัวละคร)
- Combat ใหม่ต้อง balance ใหม่ (win rate Story 70–92% ตาม ADR-0014)
