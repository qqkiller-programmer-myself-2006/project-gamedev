# Thai localisation glossary

คำแปลในแคตตาล็อก `i18n/th.po` (และข้อความ UI ที่จะแปลในเฟส B) ใช้คำเหล่านี้เป็นมาตรฐานเดียวกัน
คงปุ่มลัด เช่น `[F]`, `[1]`, ตัวเลข และ placeholder เช่น `{target}` ไว้ตามต้นฉบับ
msgstr ต้องไม่มีอักษรอังกฤษ ยกเว้นปุ่มลัด และอักษรย่อชื่อพ่อ `E` ในเนื้อเรื่อง (เป็นเบาะแส จึงคงไว้)
