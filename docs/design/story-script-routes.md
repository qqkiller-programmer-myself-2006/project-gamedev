# บทเรื่องแยกตามรูท และการรองรับการเปลี่ยนอาชีพ (ร่างที่ 1)

ต่อจาก [story-script-draft.md](story-script-draft.md) (บทหลัก Layer 1–5 และฉากตัดสินใจ) ไฟล์นี้เขียน **บทเฉพาะของแต่ละรูท (บท 6A/6B/6C)** และ **ระบบบทที่รองรับการที่ผู้เล่นเปลี่ยนอาชีพของตัวละคร**
สถานะ: ร่างเพื่อรอรีวิว ยังไม่ใส่ลง `content/story_mode.json` น้ำเสียงตัวละครตาม MBTI ใน story-script-draft.md (ไอคิว INTJ หัวหน้าทีม, ฟีฟ่า ENFP, เค้ก ISFJ, ตาต้า ISTJ, เมย์ ESTJ, แนนนี่ ISTP)

## ส่วนที่ 1 — โครงบทเฉพาะรูท

หลังฉากตัดสินใจ (CH) ที่ประตูถ้ำ เกมแตกเป็น 3 รูท แต่ละรูทมี **การต่อสู้สุดท้ายต่างกัน** (ต่อสู้นี้ปิดท้ายการเดินทางเหมือนที่ Guardian Boss ปิดท้ายเดิม)

| รูท | บทเปิด | การต่อสู้สุดท้าย | บทปิด |
| --- | --- | --- | --- |
| 1 ทุกคู่ได้คู่กัน | 6A-1 | สู้เซลเลนแบบ "บททดสอบ" (Guardian Boss เดิม) | 6A-2, 6A-3 |
| 2 ไอคิวเลือกแนนนี่ | 6B-1 | สู้เพื่อนทั้ง 4 (ไอคิวตายไม่ได้ มี Auto) | 6B-2 |
| 3 ถูกหักหลัง | 6C-1 | สู้เซลเลน (Guardian Boss เดิม) | 6C-2, 6C-3 |

เกมแพ้ในรูท 1 และ 3 ใช้ฉากแพ้ Layer 5 เดิม ส่วนรูท 2 ไอคิวตายไม่ได้ จึงไม่มีฉากแพ้ในการต่อสู้นั้น (ถ้าเพื่อนครบ 4 ล้มหมดจึงจบ)

### รูท 1 — บท 6A "เสียงที่ไม่เคยหาย"

**6A-1 ประตูก้อง** (ก่อนสู้)
- **ไอคิว** (เรียบ ชัดเจน): "ทุกคนฟังฉัน เราจะไม่ฆ่าเซลเลน และจะไม่ปล่อยให้ใครฆ่าแนนนี่"
- **เมย์** (ปลุกไฟ): "ได้ยินหัวหน้าแล้ว! ใครไม่เห็นด้วยบอกตอนนี้ ไม่มีใครใช่ไหม ดี"
- **เค้ก** (นุ่ม): "ไอคิว…เธอเชื่อใจเราพอแล้วใช่ไหม" — **ไอคิว**: "ฉันเชื่อ"
- **เซลเลน** (ทุ้มต่ำ): "ข้าไม่ต้องการเลือด แต่ประตูนี้ปล่อยให้ผ่านโดยไม่พิสูจน์ใจไม่ได้ มาเถอะ ข้าจะทดสอบเจ้า"
`[การต่อสู้: บททดสอบของเซลเลน]` (เซลเลนไม่โจมตีเพื่อฆ่า ฉากข้อความสะท้อนว่าการต่อสู้คือบททดสอบ)

**6A-2 เสียงกระดิ่ง** (หลังชนะ)
- **เซลเลน** (เบา): "พอแล้ว พวกเจ้าสู้เพื่อกันและกัน ข้าเห็นแล้ว"
ไอคิวก้าวไปหาแนนนี่ ทุกคนเงียบ ไอคิวสั่นกระดิ่ง เสียงก้องไปทั้งถ้ำ
- **แนนนี่** (ห้วน น้ำตาไหล): "…มาช้านะ"
- **ไอคิว** (ยิ้มครั้งแรก): "ฉันไม่ได้ลืม แค่ไม่ได้เจอ" `[เพลงจบ เวอร์ชัน A เริ่ม]`

**6A-3 สิ่งที่ไม่เคยพูด** (ปิดเรื่อง)
- ฟีฟ่า (พูดไม่หยุดมาตลอด แล้วเงียบ): "…ฉันชอบเธอ" — เค้ก (ยิ้ม): "รู้อยู่แล้ว"
- ตาต้า: "ต่อไปฉันถือให้ทุกอย่างได้ไหม" — เมย์ (ตะโกนเสียงสั่น): "…ก็ตามแผนสิ! ถือเลย!"
- ไอคิวกับแนนนี่: จับมือ ไม่พูดอะไร
- เซลเลนเปิดประตู สองโลกเดินข้ามถึงกันได้ ภาพทั้งหกคนบนเส้นทางที่มนุษย์กับอสูรเดินร่วมกัน

### รูท 2 — บท 6B "สิ่งที่แลก"

**6B-1 หันหลัง** (ก่อนสู้)
- **ไอคิว** (เย็น): "ฉันเลือกแล้ว ใครขวางทางฉัน ฉันจะผ่านไป"
- **ฟีฟ่า** (ตกใจ): "ไอคิว ล้อเล่นใช่ไหม— บอกว่าล้อเล่นสิ แล้วฉันจะเล่นมุกให้ฟังทั้งคืน"
- **เค้ก** (เบา): "ไอคิว ฉันเผื่อข้าวไว้ให้หกคนมาตลอดเลยนะ"
- **ตาต้า** (นิ่ง): "ถ้านายจะไป ก็ต้องผ่านพวกเราก่อน"
- **เมย์** (ปลุกไฟ ทั้งน้ำตา): "ไอคิว! นายเป็นหัวหน้าเรานะ! ตื่นสิ!"
- **ไอคิว** (เย็นชา): "ฉันคำนวณแล้ว ฉันเสียเธอไปครั้งเดียวก็เกินพอ"
`[การต่อสู้: เพื่อน 4 คน — ไอคิวตายไม่ได้ ใช้ปุ่ม Auto ได้ ศัตรูใช้อาชีพที่ผู้เล่นเลือกไว้]`
แต่ละคนที่ล้มพูดว่า **"เราไปผิดพลาดกันตรงไหน"** ตามบุคลิก: ฟีฟ่า (พูดเหมือนมุกที่ตลกไม่ออก), เค้ก (เบาๆ), ตาต้า (นิ่งแบบข้อเท็จจริง), เมย์ (ทั้งน้ำตา)

**6B-2 เข้าประตู** (หลังสู้ `[วิดีโอ E2b]`)
ไอคิวยืนท่ามกลางเงียบ แนนนี่เดินมา
- **แนนนี่** (นิ่ง ไม่มีมุก): "…ทำไมข้าถึงเจ็บ"
- **ไอคิว** (เบามาก): "ไม่ต้องเข้าใจ เดินไปกับฉันก็พอ"
ทั้งสองเดินเข้าประตูราตรี เสียงกระดิ่งค่อยๆ เบาลง `[เพลงจบ เวอร์ชัน B]` `[วิดีโอ E2]` ภาพถ้ำว่างเปล่า มีกระดิ่งหนึ่งใบวางอยู่

### รูท 3 — บท 6C "คำสั่งที่ไม่ใช่ของเรา"

**6C-1 ตามภารกิจ** (ก่อนสู้)
- **ไอคิว** (เด็ดขาด): "ภารกิจต้องจบ เป็นคำสั่งของฉัน ไม่ใช่ของจักรแห่งอรุณ" (ไอคิวตัดสินใจโดยเหตุผล เชื่อว่าเซลเลนต้องถูกหยุดเพื่อช่วยแนนนี่ออกมา)
- **แนนนี่** (อ่านคำสั่ง): "ไม่ให้ใครผ่าน" แต่ถอยหนึ่งก้าวโดยไม่รู้ตัว
- **เมย์** (ปลุกไฟ): "ทุกคน! รวมใจ! ไอคิวคิดแล้ว เราทำตามที่ตกลง!"
`[การต่อสู้: เซลเลน (Guardian Boss เดิม)]` เซลเลนไม่สู้เพื่อฆ่า แต่ป้องกันประตู

**6C-2 กองทัพ** (หลังชนะ)
เซลเลนยอมถอย ไม่ตาย แนนนี่ล้มลงสลบ กองทัพจักรแห่งอรุณบุกเข้าถ้ำ
- **อัครเสน** (ผ่านผู้บัญชาการ): "ปิดถ้ำ ทั้งหมดที่อยู่ข้างในถูกแปดเปื้อนแล้ว"
- **ไอคิว** (เย็น): "…พวกเขารู้ตั้งแต่ต้นว่าจะเกิดอะไรขึ้น"
- **เซลเลน** (ทุ้ม): "ทางลับทางซ้าย ข้าจะถ่วงพวกมันไว้ให้"

**6C-3 ทางลับ** (ปิดเรื่อง)
- **ไอคิว** (เด็ดขาด): "ถอย ตาต้า อุ้มแนนนี่"
- **ตาต้า**: "ตามแผน"
- **เมย์** (ปลุกไฟ): "ไม่ต้องกลัว! เรายังอยู่ครบ วิ่งเร็ว!" **เค้ก**: "ฉันอยู่ข้างหลังนะ ไม่ทิ้งใคร"
ทั้งหกคนหนีออกจากถ้ำ `[เพลงจบ เวอร์ชัน C]` `[วิดีโอ E3]` ภาพสุดท้ายคือแผนที่ที่ไอคิววงเวียงอรุณไว้ ไอคิว: "ตอนนี้เรามีคำถามที่ต้องไปเอาคำตอบแล้ว"

## ส่วนที่ 2 — รองรับการเปลี่ยนอาชีพ

### กติกา
- **กลุ่มที่เปลี่ยนได้:** ไอคิว ฟีฟ่า ตาต้า เลือกจาก Assassin / Archer / Guardian; เค้ก เมย์ เลือกจาก Mage / Support / Healer
- **Cutscene วิดีโอไม่ขึ้นกับอาชีพ** (ชุดเรื่องตายตัว) อาชีพมีผลเฉพาะ **ข้อความในเกม** (dialogue) และฉาก 3D/portrait
- **บทหลักเขียนแบบไม่ขึ้นกับอาชีพ** แล้วเพิ่ม "ประโยคเฉพาะอาชีพ" เฉพาะจุดที่กำหนด (class beat) เท่านั้น เพื่อไม่ให้ต้องเขียนซ้ำทั้งเรื่อง
- ผู้เล่นเลือกอาชีพได้อิสระต่อกัน (ตัวละครชายสองคนเลือกอาชีพเดียวกันได้หรือไม่ ต้องยืนยันกับกติกาตั้งค่าอาชีพ — ดูคำถามเปิด)

### กลไกในข้อมูลบท (ข้อเสนอ ไม่แตะ server)
บทอยู่ฝั่ง client (`content/story_mode.json`) และ `StoryDirector` เห็น snapshot ที่มีอาชีพของตัวละครอยู่แล้ว จึงเพิ่มได้โดยไม่แก้ `MatchServer`:

1. **ตัวแปรข้อความ:** `{cls:iq}` แทนด้วยชื่ออาชีพไทยของไอคิวตอนนั้น (นักฆ่า / นักธนู / ผู้พิทักษ์ / นักเวท / ซัพพอร์ต / ฮีลเลอร์) ใช้ชื่อตาม `docs/design/thai-glossary.md` (ต้องเพิ่ม Support และ Healer ใน glossary ด้วย)
2. **ประโยคแปรผัน:** แต่ละบรรทัดมี `text` เริ่มต้นเสมอ และมี `variants` เป็นทางเลือก
   ```json
   {"speaker": "iq", "text": "พร้อมแล้ว", "variants": {"iq": {"assassin": "...", "archer": "...", "guardian": "..."}}}
   ```
   key แรกคือตัวละครที่ต้องดูอาชีพ ถ้าไม่ตรงกับตัวแปรใดให้ใช้ `text`
3. **ธงรูท:** ผลของฉากตัดสินใจเก็บเป็นค่า route (1/2/3) ใน Story save และ snapshot เพื่อให้ client เลือกบท 6A/6B/6C ได้ และ **server ต้องรู้ route เพื่อเลือกการต่อสู้สุดท้าย** (ดูข้อควรตัดสินใจข้างล่าง)
4. **Trigger ใหม่:** นอกจาก trigger เดิม (first_combat_won, class_gained, story_clue, merchant_first, rest_first, before_boss, boss_won, party_defeated) เพิ่ม `layer_N_enter`, `route_decision`, `route_1_intro`, `route_2_intro`, `route_3_intro` และฉากแพ้ `defeat_layer_N`

### Class beat (จุดที่มีประโยคเฉพาะอาชีพ)
เขียนเป็นตัวอย่าง (ไอคิว 3 อาชีพ และเค้ก 3 อาชีพ) ที่เหลือเขียนแบบเดียวกันตอนสร้าง content

**Beat A — พร้อมก่อนเข้าถ้ำ (before_boss)** เป็นบทที่ทุกคนบอกความพร้อมของตัวเอง
- **ไอคิว** (INTJ หัวหน้า)
  - นักฆ่า: "ฉันจะอยู่ในเงา ตัดทางเดียวที่ต้องตัด"
  - นักธนู: "ฉันคุมระยะ ทุกคนอยู่ในสายตาฉัน"
  - ผู้พิทักษ์: "ฉันยืนข้างหน้า ผ่านฉันไปไม่ได้"
- **เค้ก** (ISFJ)
  - ซัพพอร์ต: "ทุกคนมีอะไรให้ฉันช่วยบ้างไหม ฉันเตรียมไว้หมดแล้ว"
  - ฮีลเลอร์: "ฉันไม่เก่งเท่าแนนนี่ แต่ฉันจะไม่ให้ใครล้ม"
  - นักเวท: "ฉันไม่ได้เก่งเรื่องรบ แต่ก็ไม่ปล่อยให้ใครต้องรบคนเดียว"

**Beat B — ไอคิวในรูท 2 (6B-1 ก่อนสู้)**
- นักฆ่า: "ฉันรู้ทุกจุดอ่อนของพวกนาย เพราะฉันฝึกกับพวกนายมา"
- นักธนู: "ฉันรู้ระยะของพวกนายทุกคน ฉันยิงถูกทุกคน"
- ผู้พิทักษ์: "ฉันไม่ต้องรุก แค่ยืนอยู่ ฉันก็ไม่แพ้"

**Beat C — เมื่อมีฮีลเลอร์ในทีม (Layer 2 ฉากไดอารี่ของแนนนี่)** ถ้าเค้กหรือเมย์เป็นฮีลเลอร์ เพิ่มประโยค: "เธอเคยเป็นฮีลเลอร์คนเดียวของทีม ตอนนี้…ฉันใส่รองเท้าเธอไม่พอดีหรอก แต่ฉันจะพยายาม"

**Beat D — ได้อาชีพ (class_gained)** ใช้ชื่ออาชีพที่ได้ในประโยคเดียวต่อคน เช่น "{cls:fifa} ก็เท่ดีนะ" ต้องมีประโยคเฉพาะสำหรับ Support และ Healer เพราะเป็นอาชีพใหม่

### ข้อที่ต้องตัดสินใจเพิ่ม (กระทบระบบ)
1. **server ต้องรู้ route** เพื่อเลือกการต่อสู้สุดท้าย (รูท 2 ต่างจาก 1/3) ข้อเสนอ: เพิ่มคำสั่ง `choose_route` ที่ server เก็บใน state และ Story save ต้องบันทึก/ตรวจ route ตามกติกา validation เดิม (ADR-0014) ต้องบันทึกเพิ่มใน ADR-0016
2. **อาชีพซ้ำกัน:** ตัวละครชายสองคนเลือกอาชีพเดียวกันได้ไหม ผมตรวจโค้ดตั้งค่าแล้วไม่พบการห้ามซ้ำ ถ้าจะห้ามต้องบอก
3. **จำนวนบรรทัดแปรผัน:** class beat ทุกจุด × 5 ตัวละคร × 3 อาชีพ = หลายสิบบรรทัด ข้อเสนอ: เขียนครบเฉพาะ beat A และ B ก่อน ที่เหลือใช้ `text` ทั่วไป
