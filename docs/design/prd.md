# PRD — BEYOND THE WORLD'S END

## 1. Product Overview

**ชื่อเกม:** BEYOND THE WORLD'S END  
**ประเภทเกม:** Fantasy Adventure / Turn-Based RPG / Co-op / Roguelite / Branching Adventure  
**จำนวนผู้เล่น:** 1–4 คน  
**แพลตฟอร์มเป้าหมายเบื้องต้น:** PC  
**Engine:** Godot  
**ภาษาโปรแกรม:** GDScript  
**กลุ่มเป้าหมาย:** อายุ 12 ปีขึ้นไปจนถึงวัยผู้ใหญ่  

### High Concept
เกมผจญภัยแฟนตาซีแบบ Turn-Based RPG ที่ผู้เล่นรับบทเป็นพี่น้อง 4 คน ออกเดินทางตามรอยพ่อที่หายสาบสูญ เพื่อค้นหา **The Sacred Chalice** จอกศักดิ์สิทธิ์ซึ่งอาจเป็นหนทางเดียวในการรักษาแม่ที่กำลังจะเสียชีวิต

ผู้เล่นเริ่มต้นแบบ **Classless** และค่อย ๆ ค้นพบอาชีพใหม่จากสถานที่ เหตุการณ์ และเส้นทางที่ทีมเลือกเดิน

---

## 2. Core Fantasy

ผู้เล่นควรรู้สึกว่าเป็น “กลุ่มพี่น้องธรรมดาที่ค่อย ๆ เติบโตเป็นนักผจญภัย” ผ่านการเดินทางที่ไม่มีใครรับประกันว่าจะรอดกลับมา

หัวใจสำคัญของประสบการณ์คือ:

- การเดินทางร่วมกับเพื่อน
- การตัดสินใจเลือกเส้นทาง
- การค้นพบ Class และ Build ระหว่างการผจญภัย
- การต่อสู้แบบวางแผนเป็น Turn
- การตามรอยพ่อผ่านเบาะแสที่กระจายอยู่ทั่วโลก
- การค้นหาความจริงของ The Sacred Chalice
- การตัดสินใจว่าครอบครัวมีค่ามากพอที่จะแลกกับอะไร

---

## 3. Story Summary

ไม่มีใครรู้ว่าโลกมีจุดสิ้นสุดอยู่จริงหรือไม่

บนแผนที่โบราณ ดินแดนที่มนุษย์รู้จักสิ้นสุดลงที่มหาสมุทรทางตะวันตกซึ่งเรียกว่า **Beyond Sea** ทะเลที่ไม่มีเรือลำใดเคยแล่นกลับมา

ตำนานกล่าวว่า ณ จุดสิ้นสุดของโลก มี **The Sacred Chalice** ตั้งอยู่ท่ามกลางน้ำพุแห่งชีวิต ผู้ใดได้ดื่มจากจอกจะได้รับการชำระโรคร้ายทั้งปวง

เมื่อแม่ของพี่น้องทั้งสี่ล้มป่วยด้วยโรคประหลาดที่ไม่มีผู้ใดรักษาได้ พ่อของพวกเขาจึงออกเดินทางตามหาจอกศักดิ์สิทธิ์

เขาสัญญาว่าจะกลับมา

แต่หลังจากผ่านไปสามปี เขากลับหายสาบสูญโดยไม่มีแม้แต่หลักฐานว่าเสียชีวิตหรือไปถึงที่ใด

เมื่ออาการของแม่ทรุดหนักจนแทบไม่มีเวลาเหลือ พี่น้องทั้งสี่จึงเปิดหีบเก่าของพ่อ และพบแผนที่ บันทึก และข้อความที่เขาทิ้งไว้:

> “หากข้าไม่กลับมา จงอย่าตามข้ามา”

และอีกข้อความหนึ่งที่ถูกเขียนภายหลัง:

> “แต่หากไม่มีทางเลือกเหลืออยู่แล้ว… จงตามเส้นทางที่ข้าทิ้งไว้”

นั่นคือจุดเริ่มต้นของการเดินทาง

ทั้งสี่ไม่ได้เป็นวีรบุรุษ ไม่มีคำพยากรณ์ ไม่มีเทพเจ้าเลือกพวกเขา และไม่มีอาณาจักรใดรอให้ช่วยเหลือ

พวกเขาเป็นเพียงลูกสี่คนที่กำลังจะสูญเสียแม่ และกำลังตามหาพ่อที่อาจตายไปแล้ว

ตลอดเส้นทาง พวกเขาจะพบร่องรอยของพ่อ ทั้งค่ายพัก ข้อความ บันทึก ผู้ร่วมทางเก่า และหลักฐานเกี่ยวกับความจริงของจอกศักดิ์สิทธิ์

ยิ่งเข้าใกล้จุดสิ้นสุดของโลกมากเท่าไร พวกเขายิ่งพบว่าจอกอาจมีอยู่จริง แต่สิ่งนั้นอาจไม่ใช่ “ของขวัญจากเทพเจ้า” อย่างที่ผู้คนเชื่อ

มีบันทึกหนึ่งกล่าวไว้ว่า:

> “ไม่มีสิ่งใดในโลกสามารถมอบชีวิต โดยไม่พรากบางสิ่งไปเป็นการตอบแทน”

คำถามสุดท้ายจึงไม่ใช่เพียงว่า The Sacred Chalice มีอยู่จริงหรือไม่

แต่คือ:

**พวกเขายินดีจะเสียอะไร เพื่อให้แม่มีชีวิตอยู่ต่อไป?**

## 4. Player Goal

เป้าหมายหลักของผู้เล่นคือ:

1. เดินทางผ่าน Region ต่าง ๆ ของโลก
2. ค้นหาเบาะแสเกี่ยวกับพ่อที่หายสาบสูญ
3. พัฒนาตัวละครจาก Classless ไปสู่ Class ระดับสูง
4. เอาชนะ Guardian Boss ประจำแต่ละ Region
5. เดินทางข้าม Beyond Sea
6. ไปให้ถึง The End of the World
7. ค้นหา The Sacred Chalice
8. เปิดเผยความจริงของพ่อ ครอบครัว และโลก
9. ตัดสินใจเกี่ยวกับราคาที่ต้องจ่ายเพื่อช่วยชีวิตแม่

## 5. Target Audience

**อายุ:** 12 ปีขึ้นไป

**กลุ่มผู้เล่นหลัก:**
- ผู้เล่น RPG
- ผู้เล่นที่ชอบ Fantasy Adventure
- ผู้เล่นที่ชอบ Turn-Based Combat
- ผู้เล่นที่ชอบเล่น Co-op กับเพื่อน
- ผู้เล่นที่ชอบ Roguelite / Branching Path
- ผู้เล่นที่ชอบการสร้าง Build และ Class Evolution

### Design Principle
ระบบพื้นฐานต้องเข้าใจง่าย แต่มีความลึกจากการเลือก Skill, Class, Equipment และ Route

ผู้เล่นใหม่ควรสามารถเล่นได้ด้วยคำสั่งพื้นฐาน:
- Attack
- Skill
- Defend
- Item

ขณะที่ผู้เล่นที่มีประสบการณ์สามารถวางแผน Party Composition และ Class Build ได้ลึกขึ้น

## 6. Core Gameplay Loop

**เลือกเส้นทาง → Encounter → Combat / Event → รับรางวัล → พัฒนาตัวละคร → โหวตเลือกเส้นทางใหม่ → Guardian Boss → เลือก Region ถัดไป**

รายละเอียด:

1. ทีมเข้าสู่ Layer ใหม่
2. เกมสุ่มสถานที่หรือเหตุการณ์ให้เลือก 2–3 ทาง
3. ผู้เล่นโหวตเลือกเส้นทาง
4. ทีมเดินทางไปยังตัวเลือกที่ได้คะแนนสูงสุด
5. เกิด Encounter
6. Encounter อาจเป็น:
   - Combat
   - Merchant
   - Rest
   - Treasure
   - Story Event
   - Class Encounter
   - Mystery Event
7. หากเป็น Combat ผู้เล่นต่อสู้แบบ Turn-Based
8. ได้ EXP / Gold / Item / Equipment / Story Clue
9. เดินทางต่อไปยัง Layer ถัดไป
10. เมื่อถึงปลาย Region จะพบ Guardian Boss
11. เอาชนะ Boss เพื่อปลดล็อก Region ใหม่

---

## 7. World Structure

โครงสร้างโลกแบ่งเป็นหลาย **Region**

ตัวอย่าง:

- Forest
- Ancient Ruins
- Old Kingdom
- Highlands
- Desert
- Frozen Land
- Dark Castle
- Beyond Sea
- The End of the World

### Region Structure

แต่ละ Region มีประมาณ **11 Layers**

ตัวอย่าง:

```text
START
  ↓
Layer 1
  ↓
Choose Path
  ↓
Layer 2
  ↓
Encounter
  ↓
...
  ↓
Layer 10
  ↓
Layer 11
  ↓
Guardian Boss
  ↓
Choose Next Region
```

แต่ละ Layer ไม่จำเป็นต้องเป็น Map เดิมหรือ Event เดิมทุกครั้ง

ระบบใช้ Encounter Pool เพื่อเพิ่ม Replayability

---

## 8. Path Voting System

หลังจบ Encounter ระบบจะแสดงเส้นทาง 2–3 ตัวเลือก

ตัวอย่าง:

- Follow the Stream
- Travelling Merchant
- Abandoned Cabin
- Ancient Ruins
- Hunter Camp
- Dangerous Cave

ผู้เล่นมีเวลาจำกัดในการโหวต

### Voting Rules

- ผู้เล่นแต่ละคนมี 1 Vote
- เส้นทางที่ได้คะแนนสูงสุดเป็นผู้ชนะ
- ถ้าเสมอ ให้สุ่มจาก Choice ที่มีคะแนนเท่ากัน
- ใน Single Player ผู้เล่นเลือกเองโดยตรง

ระบบนี้มีผลต่อ:
- Encounter ที่จะพบ
- Item ที่จะได้รับ
- Class ที่อาจค้นพบ
- Story Clue
- Difficulty
- Risk / Reward
- Region Route

---

## 9. Combat System

ระบบต่อสู้เป็น **Turn-Based Combat**

### Main Actions

- **Attack** — โจมตีพื้นฐาน
- **Skill** — ใช้ความสามารถเฉพาะ Class
- **Defend** — ลดความเสียหาย / เพิ่ม Defense
- **Item** — ใช้ไอเทม

### Turn Flow

```text
Turn Start
  ↓
Select Action
  ↓
Select Target
  ↓
Resolve Action
  ↓
Status Effect
  ↓
Next Character
```

### Turn Order

คำนวณจากค่า Speed / Agility ของตัวละครและศัตรู

## 10. Multiplayer

รองรับผู้เล่น:

- Single Player
- 2 Players
- 3 Players
- 4 Players

ใน Co-op ผู้เล่นแบ่งกันควบคุมตัวละครใน Party

### Difficulty Scaling

จำนวนผู้เล่นมีผลต่อ:
- Enemy HP
- Enemy Damage
- จำนวน Enemy
- Boss HP
- Boss Phase

จุดประสงค์คือให้ความยากใกล้เคียงกันไม่ว่าจะเล่น 1 หรือ 4 คน

---

## 11. Character System

ตัวละครหลักทั้งหมดเริ่มต้นเป็น:

**Classless**

Classless มีคำสั่งพื้นฐาน:
- Attack
- Defend
- Item

ผู้เล่นยังไม่มีความสามารถเฉพาะทาง

Class จะถูกค้นพบระหว่างการผจญภัย

---

## 12. Tier 1 Classes

ใน Forest Region ผู้เล่นมีโอกาสพบ Class Encounter ระดับ Tier 1

### Swordsman
**Role:** Melee DPS

จุดเด่น:
- Damage สมดุล
- ใช้งานง่าย
- Skill ระยะประชิด

### Archer
**Role:** Ranged DPS

จุดเด่น:
- Speed สูง
- Critical
- โจมตีระยะไกล

### Mage
**Role:** Magic DPS / AoE

จุดเด่น:
- Magic Damage
- AoE
- Elemental Skill

### Guardian
**Role:** Tank / Defense

จุดเด่น:
- HP / Defense สูง
- Protect Ally
- ลด Damage

---

## 13. Class Discovery

ผู้เล่นไม่ได้เลือก Class ตั้งแต่เริ่มเกม

Class ต้องถูกค้นพบจาก Encounter

ตัวอย่าง:

### Old Swordsman Event

ผู้เล่นพบชายชราฝึกดาบอยู่หน้ากระท่อม

เมื่อผ่าน Challenge:

**Class Discovered: Swordsman**

---

### Hunter Camp

Encounter Pool:

- Archer Class Event
- Wolf Combat
- Hunter Merchant
- Rare Item
- Secret Event

ดังนั้นการเลือก Hunter Camp ไม่ได้รับประกันว่าจะได้ Archer ทุกครั้ง

---

## 14. Class Evolution

เมื่อผู้เล่นผ่าน Region แรก Class สามารถพัฒนาไปเป็น Tier 2 ได้

ตัวอย่าง:

```text
Swordsman
├── Knight
├── Berserker
└── Spellblade
```

เส้นทาง Evolution ขึ้นอยู่กับ Region และ Event ที่ผู้เล่นเลือก

ตัวอย่าง:

- Old Kingdom → Knight
- Highlands → Berserker
- Ancient Ruins → Spellblade

แนวคิดหลักคือ:

**World Route = Character Build**

## 15. Encounter Types

### Combat
พบศัตรูและต่อสู้แบบ Turn-Based

### Merchant
ซื้อ / ขาย Item และ Equipment

### Rest Area
ฟื้น HP / Resource

### Treasure
รับ Item หรือ Equipment

### Story Event
ค้นพบเรื่องราวของโลกหรือพ่อ

### Class Encounter
ปลดล็อก Class หรือ Evolution

### Mystery Event
ผลลัพธ์ไม่แน่นอน มี Risk / Reward สูง

## 16. Story Progression

แต่ละ Region จะมีเบาะแสของพ่อ

ตัวอย่าง:

- Campfire ที่ถูกทิ้งไว้
- บันทึกการเดินทาง
- ข้อความบนกำแพง
- ผู้ร่วมทางเก่าของพ่อ
- Map Fragment
- Artifact
- Secret Dungeon

เรื่องของพ่อจะค่อย ๆ เปลี่ยนจาก:

> “ชายคนหนึ่งที่ออกเดินทางเพื่อช่วยภรรยา”

ไปสู่:

> “นักเดินทางที่ค้นพบความจริงบางอย่างเกี่ยวกับ The Sacred Chalice”

และสุดท้ายผู้เล่นจะค้นพบว่าความลับนั้นเกี่ยวข้องกับเหตุผลที่คนที่ออกตามหาจอกไม่เคยกลับมา

## 17. Narrative Themes

ธีมหลักของเรื่อง:

- ครอบครัว
- ความหวัง
- การสูญเสีย
- การเสียสละ
- ความรักของพ่อแม่และลูก
- ความสัมพันธ์ของพี่น้อง
- ราคาของชีวิต
- การยอมรับความตาย
- ความจริงกับตำนาน
- ความต้องการมีชีวิตอยู่ตลอดไป

คำถามหลักของเรื่อง:

**“ชีวิตหนึ่งชีวิตมีค่ามากพอให้เราเสียอะไรไปเพื่อรักษามันไว้?”**

## 18. Win Condition

ผู้เล่นต้องเดินทางไปถึง **The End of the World**

และเผชิญกับเหตุการณ์สุดท้ายที่เกี่ยวข้องกับ:

- The Sacred Chalice
- พ่อ
- โรคของแม่
- ความจริงของโลก
- ราคาของการใช้จอก

Final Choice ของผู้เล่นควรมีผลต่อ Ending

## 19. Potential Endings

ตัวอย่างแนวทาง:

### Save Mother
ใช้พลังของจอกเพื่อรักษาแม่ แต่ต้องจ่ายราคาบางอย่าง

### Reject the Chalice
ปฏิเสธการใช้จอกหลังค้นพบความจริง

### Break the Cycle
ทำลายต้นกำเนิดของจอกหรือคำสาป

### Father's Choice
ค้นพบสิ่งที่พ่อเลือกไว้ก่อนหน้า และตัดสินใจว่าจะทำตามหรือไม่

จำนวน Ending จริงสามารถลดตาม Scope การพัฒนา

## 22. Game Pillars

### 1. Journey Together
ผู้เล่นต้องรู้สึกว่ากำลังเดินทางร่วมกับ Party

### 2. Choice Matters
เส้นทางที่เลือกส่งผลต่อ Gameplay และ Build

### 3. Grow Through Adventure
Class และความสามารถมาจากสิ่งที่ผู้เล่นพบระหว่างทาง

### 4. Tactical but Accessible

### 5. Mystery Beyond the Horizon

## 23. Elevator Pitch

**BEYOND THE WORLD'S END** คือเกม Fantasy Co-op Turn-Based RPG สำหรับผู้เล่น 1–4 คน ที่เล่าเรื่องพี่น้องสี่คนออกเดินทางตามหาพ่อที่หายสาบสูญและจอกศักดิ์สิทธิ์ซึ่งอาจช่วยชีวิตแม่ได้

ผู้เล่นเริ่มต้นแบบ Classless และสร้างตัวละครผ่าน Class ที่ค้นพบจากเส้นทางและเหตุการณ์ระหว่างการเดินทาง โดยทั้งทีมต้องร่วมกันโหวตว่าจะเดินทางไปไหนต่อ

ทุก Region จะนำพวกเขาเข้าใกล้ทั้ง The End of the World และความจริงที่ว่า พลังในการช่วยชีวิตอาจต้องแลกด้วยราคาที่ไม่มีใครอยากจ่าย
