# .ai/
ไฟล์ช่วยจัดงานให้ AI ในรีโป เช่น task specs, checkpoint และ runner อยู่ที่นี่.
รายการงานอยู่ใน `tasks/`; สถานะและคำสั่งปัจจุบันดูที่ `checkpoint.md` กับ `run-agent.ps1`.
ผู้วางแผนดูแล task specs; executor ทำตามขอบเขตที่ไฟล์งานกำหนด.
บันทึกเก่าเก็บไว้เพื่ออ้างอิงและไม่ควรถูกลบระหว่าง tidy ทั่วไป.
